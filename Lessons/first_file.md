Start by installing the library with `pip install aiden3drenderer` (make sure the IDE's python instance is the same one that the library was installed in)

then, students should make a new python file, making sure to have `from aiden3drenderer import Renderer3D` at the top
use some examples to lead them into making their first file. 
One such example is as follows:
```python
from aiden3drenderer import Renderer3D
renderer = Renderer3D()
renderer.run()
```
